# Elevation and motion

## Elevation

Two elevations and one focus ring.

| Token                     | Use it for                                                              |
| ------------------------- | ----------------------------------------------------------------------- |
| `--timbre-shadow-sm`      | Resting surfaces that need a little lift: cards, menus.                 |
| `--timbre-shadow-overlay` | Elements above the page: dialogs, popovers.                             |
| `--timbre-focus-ring`     | Keyboard focus on every interactive element. Use with `:focus-visible`. |

The focus ring is made of two rings: an inner one in the surface colour and an outer one in `--timbre-color-focus`. It stays visible on any background, in both themes.

## Motion

| Token                       | Value                        | Use it for                                 |
| --------------------------- | ---------------------------- | ------------------------------------------ |
| `--timbre-duration-fast`    | 120ms                        | Hover and press feedback, colour changes.  |
| `--timbre-duration-overlay` | 180ms                        | Dialogs and popovers opening and closing.  |
| `--timbre-ease-out`         | `cubic-bezier(0.2, 0, 0, 1)` | Every transition: fast start, gentle stop. |

When the user asks the system for [reduced motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion), both durations become `0ms`.
