## Which file to use

| File                           | When                                                    |
| ------------------------------ | ------------------------------------------------------- |
| `monogram.svg`                 | The primary logo, from 32px up, on light backgrounds.   |
| `monogram-dark.svg`            | The primary logo on dark backgrounds.                   |
| `monogram-small.svg`           | Below 32px, for example favicons, on light backgrounds. |
| `monogram-small-dark.svg`      | Below 32px on dark backgrounds.                         |
| `glyph.svg`, `glyph-cream.svg` | The glyph alone, where a filled square is too heavy.    |

The logo colours are fixed and do not follow the theme: pick the file for the background it sits on.
