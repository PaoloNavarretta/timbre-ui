# Colors

Use **semantic tokens only**. Each row shows the token, its value in Timbre Light and Timbre Dark, and where it belongs. Every text pair meets [WCAG 2.2 AA](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) in both themes.

## Primitives

The semantic tokens point to a private palette, the primitives (`--_timbre-*`). Components and apps never use them: they can change in any release.
